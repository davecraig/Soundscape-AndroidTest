# 语音

{% if platform == "ios" %}
Soundscape 可以使用 iPhone 上安装的任何语音，但 Siri 语音除外。*Enhanced* 语音听起来最好，但必须先下载。在 iOS 设置应用中，依次进入 Accessibility > Read & Speak > Voices 并选择一个语音。在 iOS 26 之前，*Read & Speak* 名为 *Spoken Content*。要在 Soundscape 中选择语音，请打开菜单，依次选择*设置*、*音频*、*语音*。
{% else %}
Soundscape 可以使用手机上安装的任何语音。要添加语音，请打开手机的设置并找到*文字转语音输出*。要在 Soundscape 中选择语音，请打开菜单，依次选择*设置*、*音频*、*语音*。
{% endif %}
