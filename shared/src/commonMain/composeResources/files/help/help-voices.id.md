# Suara

{% if platform == "ios" %}
Soundscape dapat menggunakan suara apa pun yang terpasang di iPhone Anda, kecuali suara Siri. Suara *Enhanced* terdengar paling bagus, tetapi Anda harus mengunduhnya terlebih dahulu. Di aplikasi Pengaturan iOS, buka Accessibility > Read & Speak > Voices dan pilih sebuah suara. Sebelum iOS 26, *Read & Speak* disebut *Spoken Content*. Untuk memilih suara di Soundscape, buka menu dan pilih *Pengaturan*, lalu *Audio*, lalu *Suara*.
{% else %}
Soundscape dapat menggunakan suara apa pun yang terpasang di ponsel Anda. Untuk menambah suara, buka pengaturan ponsel dan cari *Output text-to-speech*. Untuk memilih suara di Soundscape, buka menu dan pilih *Pengaturan*, lalu *Audio*, lalu *Suara*.
{% endif %}
