# Stemmer

{% if platform == "ios" %}
Soundscape kan bruke alle stemmer som er installert på iPhonen din, bortsett fra Siri-stemmene. *Enhanced*-stemmene låter best, men du må laste dem ned først. Gå til Tilgjengelighet > Les og snakk > Stemmer i Innstillinger-appen på iOS, og velg en stemme. Før iOS 26 heter *Les og snakk* i stedet *Opplest innhold*. For å velge en stemme i Soundscape åpner du menyen og velger *Innstillinger*, deretter *Lyd* og deretter *Stemmer*.
{% else %}
Soundscape kan bruke alle stemmer som er installert på telefonen din. For å legge til stemmer åpner du telefonens innstillinger og finner *Tekst-til-tale-utdata*. For å velge en stemme i Soundscape åpner du menyen og velger *Innstillinger*, deretter *Lyd* og deretter *Stemmer*.
{% endif %}
