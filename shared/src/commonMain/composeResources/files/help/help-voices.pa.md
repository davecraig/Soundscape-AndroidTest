# ਆਵਾਜ਼ਾਂ

{% if platform == "ios" %}
Soundscape ਤੁਹਾਡੇ iPhone 'ਤੇ ਇੰਸਟਾਲ ਕੋਈ ਵੀ ਆਵਾਜ਼ ਵਰਤ ਸਕਦਾ ਹੈ, ਸਿਵਾਏ Siri ਦੀਆਂ ਆਵਾਜ਼ਾਂ ਦੇ। *Enhanced* ਆਵਾਜ਼ਾਂ ਸਭ ਤੋਂ ਵਧੀਆ ਲੱਗਦੀਆਂ ਹਨ, ਪਰ ਪਹਿਲਾਂ ਉਨ੍ਹਾਂ ਨੂੰ ਡਾਊਨਲੋਡ ਕਰਨਾ ਪੈਂਦਾ ਹੈ। iOS ਦੀ Settings ਐਪ ਵਿੱਚ Accessibility > Read & Speak > Voices 'ਤੇ ਜਾਓ ਅਤੇ ਇੱਕ ਆਵਾਜ਼ ਚੁਣੋ। iOS 26 ਤੋਂ ਪਹਿਲਾਂ *Read & Speak* ਦਾ ਨਾਮ *Spoken Content* ਹੈ। Soundscape ਵਿੱਚ ਆਵਾਜ਼ ਚੁਣਨ ਲਈ ਮੀਨੂ ਖੋਲ੍ਹੋ ਅਤੇ *ਸੈਟਿੰਗਾਂ*, ਫਿਰ *ਆਡੀਓ*, ਫਿਰ *ਆਵਾਜ਼ਾਂ* ਚੁਣੋ।
{% else %}
Soundscape ਤੁਹਾਡੇ ਫ਼ੋਨ 'ਤੇ ਇੰਸਟਾਲ ਕੋਈ ਵੀ ਆਵਾਜ਼ ਵਰਤ ਸਕਦਾ ਹੈ। ਆਵਾਜ਼ਾਂ ਜੋੜਨ ਲਈ ਆਪਣੇ ਫ਼ੋਨ ਦੀਆਂ ਸੈਟਿੰਗਾਂ ਖੋਲ੍ਹੋ ਅਤੇ *ਲਿਖਤ-ਤੋਂ-ਬੋਲੀ ਆਊਟਪੁੱਟ* ਲੱਭੋ। Soundscape ਵਿੱਚ ਆਵਾਜ਼ ਚੁਣਨ ਲਈ ਮੀਨੂ ਖੋਲ੍ਹੋ ਅਤੇ *ਸੈਟਿੰਗਾਂ*, ਫਿਰ *ਆਡੀਓ*, ਫਿਰ *ਆਵਾਜ਼ਾਂ* ਚੁਣੋ।
