# Puheen äänet

{% if platform == "ios" %}
Soundscape voi käyttää mitä tahansa iPhoneesi asennettua ääntä Siri-ääniä lukuun ottamatta. *Enhanced*-äänet kuulostavat parhailta, mutta ne on ensin ladattava. Siirry iOS:n Asetukset-sovelluksessa kohtaan Käyttöapu > Lue ja puhu > Äänet ja valitse ääni. Ennen iOS 26:ta kohdan *Lue ja puhu* nimi on *Puhuttu sisältö*. Jos haluat valita äänen Soundscapessa, avaa valikko ja valitse *Asetukset*, sitten *Ääni* ja sitten *Puheen äänet*.
{% else %}
Soundscape voi käyttää mitä tahansa puhelimeesi asennettua ääntä. Jos haluat lisätä ääniä, avaa puhelimen asetukset ja etsi kohta *Tekstistä puheeksi -toisto*. Jos haluat valita äänen Soundscapessa, avaa valikko ja valitse *Asetukset*, sitten *Ääni* ja sitten *Puheen äänet*.
{% endif %}
