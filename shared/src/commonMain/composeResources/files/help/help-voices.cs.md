# Hlasy

{% if platform == "ios" %}
Soundscape může používat jakýkoli hlas nainstalovaný v iPhonu, kromě hlasů Siri. *Vylepšené* hlasy znějí nejlépe, ale nejdřív je musíte stáhnout. V aplikaci Nastavení systému iOS přejděte na Zpřístupnění > Číst a mluvit > Hlasy a vyberte hlas. Před iOS 26 se *Číst a mluvit* jmenuje *Předčítání obsahu*. Chcete-li vybrat hlas v Soundscape, otevřete nabídku a vyberte *Nastavení*, pak *Zvuk* a pak *Hlasy*.
{% else %}
Soundscape může používat jakýkoli hlas nainstalovaný v telefonu. Chcete-li přidat hlasy, otevřete nastavení telefonu a najděte *Výstup převodu textu na řeč*. Chcete-li vybrat hlas v Soundscape, otevřete nabídku a vyberte *Nastavení*, pak *Zvuk* a pak *Hlasy*.
{% endif %}
