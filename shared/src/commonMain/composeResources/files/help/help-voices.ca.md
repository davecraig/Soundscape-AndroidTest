# Veus

{% if platform == "ios" %}
Soundscape pot fer servir qualsevol veu instal·lada al teu iPhone, excepte les veus de Siri. Les veus *Millorades* sonen millor, però primer les has de baixar. A l'aplicació de configuració d'iOS, ves a Accessibilitat > Llegir i parlar > Veus i selecciona una veu. Abans d'iOS 26, *Llegir i parlar* es diu *Contingut parlat*. Per triar una veu a Soundscape, obre el menú i selecciona *Configuració*, després *Àudio* i després *Veus*.
{% else %}
Soundscape pot fer servir qualsevol veu instal·lada al teu telèfon. Per afegir veus, obre la configuració del telèfon i busca *Sortida de text a veu*. Per triar una veu a Soundscape, obre el menú i selecciona *Configuració*, després *Àudio* i després *Veus*.
{% endif %}
