# 声

{% if platform == "ios" %}
Soundscape は、Siri の声を除き、iPhone にインストールされている声をどれでも使用できます。*Enhanced* の声が最も聞きやすいですが、先にダウンロードする必要があります。iOS の設定アプリで、[アクセシビリティ] > [読み上げと発話] > [音声] と進み、声を選択します。iOS 26 より前では、*読み上げと発話* は *読み上げコンテンツ* という名前です。Soundscape で声を選ぶには、メニューを開いて *設定*、*音声*、*声* の順に選択します。
{% else %}
Soundscape は、スマートフォンにインストールされている声をどれでも使用できます。声を追加するには、スマートフォンの設定を開いて *テキスト読み上げの出力* を探します。Soundscape で声を選ぶには、メニューを開いて *設定*、*音声*、*声* の順に選択します。
{% endif %}
