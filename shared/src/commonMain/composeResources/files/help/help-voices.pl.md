# Wybór głosu TTS

{% if platform == "ios" %}
Soundscape może używać dowolnego głosu zainstalowanego na iPhonie, z wyjątkiem głosów Siri. Głosy *Enhanced* (Ulepszone) brzmią najlepiej, ale najpierw trzeba je pobrać. W aplikacji Ustawienia systemu iOS przejdź do Dostępność > Czytanie i mówienie > Głosy i wybierz głos. Przed iOS 26 pozycja *Czytanie i mówienie* nazywa się *Mówiony tekst*. Aby wybrać głos w Soundscape, otwórz menu i wybierz *Ustawienia*, potem *Dźwięk*, a potem *Wybór głosu TTS*.
{% else %}
Soundscape może używać dowolnego głosu zainstalowanego w telefonie. Aby dodać głosy, otwórz ustawienia telefonu i znajdź *Zamiana tekstu na mowę*. Aby wybrać głos w Soundscape, otwórz menu i wybierz *Ustawienia*, potem *Dźwięk*, a potem *Wybór głosu TTS*.
{% endif %}
