# குரல்கள்

{% if platform == "ios" %}
Siri குரல்களைத் தவிர, உங்கள் iPhone-இல் நிறுவப்பட்டுள்ள எந்தக் குரலையும் Soundscape பயன்படுத்த முடியும். *Enhanced* குரல்கள் மிகச் சிறப்பாக ஒலிக்கும், ஆனால் முதலில் அவற்றைப் பதிவிறக்க வேண்டும். iOS அமைப்புகள் செயலியில் Accessibility > Read & Speak > Voices என்பதற்குச் சென்று ஒரு குரலைத் தேர்ந்தெடுக்கவும். iOS 26-க்கு முன், *Read & Speak* என்பது *Spoken Content* என்று அழைக்கப்படுகிறது. Soundscape-இல் குரலைத் தேர்வுசெய்ய, மெனுவைத் திறந்து *அமைப்புகள்*, பின்னர் *ஆடியோ*, பின்னர் *குரல்கள்* என்பதைத் தேர்ந்தெடுக்கவும்.
{% else %}
உங்கள் தொலைபேசியில் நிறுவப்பட்டுள்ள எந்தக் குரலையும் Soundscape பயன்படுத்த முடியும். குரல்களைச் சேர்க்க, தொலைபேசியின் அமைப்புகளைத் திறந்து *உரையிலிருந்து பேச்சு வெளியீடு* என்பதைக் கண்டறியவும். Soundscape-இல் குரலைத் தேர்வுசெய்ய, மெனுவைத் திறந்து *அமைப்புகள்*, பின்னர் *ஆடியோ*, பின்னர் *குரல்கள்* என்பதைத் தேர்ந்தெடுக்கவும்.
