# เสียงพูด

{% if platform == "ios" %}
Soundscape ใช้เสียงพูดใดก็ได้ที่ติดตั้งอยู่ใน iPhone ของคุณ ยกเว้นเสียง Siri เสียงแบบ *Enhanced* ฟังดีที่สุด แต่คุณต้องดาวน์โหลดก่อน ในแอปการตั้งค่าของ iOS ให้ไปที่ Accessibility > Read & Speak > Voices แล้วเลือกเสียง ใน iOS ก่อนเวอร์ชัน 26 *Read & Speak* มีชื่อว่า *Spoken Content* หากต้องการเลือกเสียงพูดใน Soundscape ให้เปิดเมนูแล้วเลือก *การตั้งค่า* จากนั้น *เสียง* แล้วเลือก *เสียงพูด*
{% else %}
Soundscape ใช้เสียงพูดใดก็ได้ที่ติดตั้งอยู่ในโทรศัพท์ของคุณ หากต้องการเพิ่มเสียงพูด ให้เปิดการตั้งค่าของโทรศัพท์แล้วหา *เอาต์พุตการอ่านออกเสียงข้อความ* หากต้องการเลือกเสียงพูดใน Soundscape ให้เปิดเมนูแล้วเลือก *การตั้งค่า* จากนั้น *เสียง* แล้วเลือก *เสียงพูด*
{% endif %}
