# Voci

{% if platform == "ios" %}
Soundscape poate folosi orice voce instalată pe iPhone-ul tău, cu excepția vocilor Siri. Vocile *Enhanced* sună cel mai bine, dar trebuie mai întâi să le descarci. În aplicația Configurări din iOS, accesează Accesibilitate > Citire și vorbire > Voci și selectează o voce. Înainte de iOS 26, *Citire și vorbire* se numește *Conținut vorbit*. Pentru a alege o voce în Soundscape, deschide meniul și selectează *Setări*, apoi *Audio*, apoi *Voci*.
{% else %}
Soundscape poate folosi orice voce instalată pe telefonul tău. Pentru a adăuga voci, deschide setările telefonului și caută *Rezultatul transformării textului în vorbire*. Pentru a alege o voce în Soundscape, deschide meniul și selectează *Setări*, apoi *Audio*, apoi *Voci*.
{% endif %}
