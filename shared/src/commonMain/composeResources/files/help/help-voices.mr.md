# आवाज

{% if platform == "ios" %}
Soundscape तुमच्या iPhone वर इन्स्टॉल केलेला कोणताही आवाज वापरू शकते, Siri चे आवाज वगळता. *Enhanced* आवाज सर्वात चांगले वाटतात, पण आधी ते डाउनलोड करावे लागतात. iOS सेटिंग्ज अॅपमध्ये Accessibility > Read & Speak > Voices वर जा आणि एक आवाज निवडा. iOS 26 पूर्वी *Read & Speak* ला *Spoken Content* म्हणतात. Soundscape मध्ये आवाज निवडण्यासाठी मेनू उघडा आणि *सेटिंग्ज*, नंतर *ऑडिओ*, नंतर *आवाज* निवडा.
{% else %}
Soundscape तुमच्या फोनवर इन्स्टॉल केलेला कोणताही आवाज वापरू शकते. आवाज जोडण्यासाठी फोनची सेटिंग्ज उघडा आणि *टेक्स्ट-टू-स्पीच आउटपुट* शोधा. Soundscape मध्ये आवाज निवडण्यासाठी मेनू उघडा आणि *सेटिंग्ज*, नंतर *ऑडिओ*, नंतर *आवाज* निवडा.
{% endif %}
