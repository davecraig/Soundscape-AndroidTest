# الأصوات

{% if platform == "ios" %}
يستطيع Soundscape استخدام أي صوت مثبّت على iPhone، ما عدا أصوات Siri. أصوات *Enhanced* هي الأفضل، لكن عليك تنزيلها أولًا. في تطبيق إعدادات iOS، انتقل إلى إمكانية الوصول > القراءة والنطق > الأصوات واختر صوتًا. قبل iOS 26، كان اسم *القراءة والنطق* هو *المحتوى المنطوق*. لاختيار صوت في Soundscape، افتح القائمة واختر *الإعدادات*، ثم *الصوت*، ثم *الأصوات*.
{% else %}
يستطيع Soundscape استخدام أي صوت مثبّت على هاتفك. لإضافة أصوات، افتح إعدادات هاتفك وابحث عن *تحويل النص إلى كلام*. لاختيار صوت في Soundscape، افتح القائمة واختر *الإعدادات*، ثم *الصوت*، ثم *الأصوات*.
{% endif %}
