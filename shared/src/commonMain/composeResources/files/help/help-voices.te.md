# వాయిస్‌లు

{% if platform == "ios" %}
Soundscape మీ iPhoneలో ఇన్‌స్టాల్ అయి ఉన్న ఏ వాయిస్‌నైనా ఉపయోగించగలదు, Siri వాయిస్‌లు తప్ప. *Enhanced* వాయిస్‌లు బాగా వినిపిస్తాయి, కానీ ముందుగా వాటిని డౌన్‌లోడ్ చేయాలి. iOS సెట్టింగ్‌ల యాప్‌లో Accessibility > Read & Speak > Voices కు వెళ్లి ఒక వాయిస్‌ను ఎంచుకోండి. iOS 26 కంటే ముందు *Read & Speak* ను *Spoken Content* అని పిలుస్తారు. Soundscapeలో వాయిస్ ఎంచుకోవడానికి, మెనూ తెరిచి *సెట్టింగ్‌లు*, తర్వాత *ఆడియో*, తర్వాత *వాయిస్‌లు* ఎంచుకోండి.
{% else %}
Soundscape మీ ఫోన్‌లో ఇన్‌స్టాల్ అయి ఉన్న ఏ వాయిస్‌నైనా ఉపయోగించగలదు. వాయిస్‌లను జోడించడానికి, మీ ఫోన్ సెట్టింగ్‌లు తెరిచి *టెక్స్ట్-టు-స్పీచ్ అవుట్‌పుట్* కోసం చూడండి. Soundscapeలో వాయిస్ ఎంచుకోవడానికి, మెనూ తెరిచి *సెట్టింగ్‌లు*, తర్వాత *ఆడియో*, తర్వాత *వాయిస్‌లు* ఎంచుకోండి.
{% endif %}
