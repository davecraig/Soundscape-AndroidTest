# Voces

{% if platform == "ios" %}
Soundscape puede usar cualquier voz instalada en tu iPhone, excepto las voces de Siri. Las voces de calidad *Mejorada* suenan mejor, pero primero debes descargarlas. En la app Ajustes de iOS, ve a Accesibilidad > Lectura y voz > Voces y selecciona una voz. Antes de iOS 26, *Lectura y voz* se llama *Contenido leído*. Para elegir una voz en Soundscape, abre el menú y selecciona *Ajustes*, después *Audio* y después *Voces*.
{% else %}
Soundscape puede usar cualquier voz instalada en tu teléfono. Para añadir voces, abre los ajustes de tu teléfono y busca *Salida de texto a voz*. Para elegir una voz en Soundscape, abre el menú y selecciona *Ajustes*, después *Audio* y después *Voces*.
{% endif %}
