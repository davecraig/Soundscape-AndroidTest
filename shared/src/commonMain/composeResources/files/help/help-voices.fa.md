# صدای موتور صوتی

{% if platform == "ios" %}
ساند‌اسکیپ می‌تواند از هر صدایی که روی iPhone شما نصب است استفاده کند، به‌جز صداهای Siri. صداهای *Enhanced* بهترین کیفیت را دارند، اما ابتدا باید آن‌ها را دانلود کنید. در اپ تنظیمات iOS به Accessibility > Read & Speak > Voices بروید و یک صدا را انتخاب کنید. پیش از iOS 26، نام *Read & Speak* عبارت *Spoken Content* است. برای انتخاب صدا در ساند‌اسکیپ، منو را باز کنید و *تنظیمات*، سپس *صدا* و سپس *صدای موتور صوتی* را انتخاب کنید.
{% else %}
ساند‌اسکیپ می‌تواند از هر صدایی که روی گوشی شما نصب است استفاده کند. برای افزودن صدا، تنظیمات گوشی را باز کنید و *خروجی تبدیل نوشتار به گفتار* را پیدا کنید. برای انتخاب صدا در ساند‌اسکیپ، منو را باز کنید و *تنظیمات*، سپس *صدا* و سپس *صدای موتور صوتی* را انتخاب کنید.
{% endif %}
