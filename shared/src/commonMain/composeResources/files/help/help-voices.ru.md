# Голоса

{% if platform == "ios" %}
Soundscape может использовать любой голос, установленный на iPhone, кроме голосов Siri. Голоса *Enhanced* звучат лучше всего, но сначала их нужно загрузить. В приложении «Настройки» iOS откройте «Универсальный доступ» > «Чтение и речь» > «Голоса» и выберите голос. До iOS 26 пункт *Чтение и речь* называется *Устный контент*. Чтобы выбрать голос в Soundscape, откройте меню и выберите *Настройки*, затем *Аудио*, затем *Голоса*.
{% else %}
Soundscape может использовать любой голос, установленный на телефоне. Чтобы добавить голоса, откройте настройки телефона и найдите пункт *Синтез речи*. Чтобы выбрать голос в Soundscape, откройте меню и выберите *Настройки*, затем *Аудио*, затем *Голоса*.
{% endif %}
