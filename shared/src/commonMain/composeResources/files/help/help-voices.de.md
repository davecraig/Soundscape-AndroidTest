# Stimmen

{% if platform == "ios" %}
Soundscape kann jede Stimme verwenden, die auf Ihrem iPhone installiert ist, außer den Siri-Stimmen. Die Stimmen mit dem Zusatz *Erweitert* klingen am besten, müssen aber zuerst heruntergeladen werden. Gehen Sie in der iOS-App „Einstellungen“ zu Bedienungshilfen > Vorlesen & Sprechen > Stimmen und wählen Sie eine Stimme. Vor iOS 26 heißt *Vorlesen & Sprechen* noch *Gesprochene Inhalte*. Um in Soundscape eine Stimme auszuwählen, öffnen Sie das Menü und wählen Sie *Einstellungen*, dann *Audio*, dann *Stimmen*.
{% else %}
Soundscape kann jede Stimme verwenden, die auf Ihrem Telefon installiert ist. Um Stimmen hinzuzufügen, öffnen Sie die Einstellungen Ihres Telefons und suchen Sie *Text-in-Sprache-Ausgabe*. Um in Soundscape eine Stimme auszuwählen, öffnen Sie das Menü und wählen Sie *Einstellungen*, dann *Audio*, dann *Stimmen*.
{% endif %}
