# Φωνές

{% if platform == "ios" %}
Το Soundscape μπορεί να χρησιμοποιήσει οποιαδήποτε φωνή είναι εγκατεστημένη στο iPhone σας, εκτός από τις φωνές της Siri. Οι φωνές *Enhanced* ακούγονται καλύτερα, αλλά πρέπει πρώτα να τις κατεβάσετε. Στην εφαρμογή Ρυθμίσεις του iOS, μεταβείτε στο Προσβασιμότητα > Ανάγνωση και ομιλία > Φωνές και επιλέξτε μια φωνή. Πριν από το iOS 26, το *Ανάγνωση και ομιλία* λέγεται *Εκφωνούμενο περιεχόμενο*. Για να επιλέξετε φωνή στο Soundscape, ανοίξτε το μενού και επιλέξτε *Ρυθμίσεις*, μετά *Ήχος* και μετά *Φωνές*.
{% else %}
Το Soundscape μπορεί να χρησιμοποιήσει οποιαδήποτε φωνή είναι εγκατεστημένη στο τηλέφωνό σας. Για να προσθέσετε φωνές, ανοίξτε τις ρυθμίσεις του τηλεφώνου και βρείτε την επιλογή *Έξοδος μετατροπής κειμένου σε ομιλία*. Για να επιλέξετε φωνή στο Soundscape, ανοίξτε το μενού και επιλέξτε *Ρυθμίσεις*, μετά *Ήχος* και μετά *Φωνές*.
{% endif %}
