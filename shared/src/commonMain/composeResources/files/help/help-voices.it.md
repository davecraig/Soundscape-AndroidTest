# Voci

{% if platform == "ios" %}
Soundscape può usare qualsiasi voce installata sul tuo iPhone, tranne le voci di Siri. Le voci *Enhanced* suonano meglio, ma devi prima scaricarle. Nell'app Impostazioni di iOS, vai su Accessibilità > Leggi e parla > Voci e seleziona una voce. Prima di iOS 26, *Leggi e parla* si chiama *Contenuti letti ad alta voce*. Per scegliere una voce in Soundscape, apri il menu e seleziona *Impostazioni*, poi *Audio*, poi *Voci*.
{% else %}
Soundscape può usare qualsiasi voce installata sul tuo telefono. Per aggiungere voci, apri le impostazioni del telefono e cerca *Output sintesi vocale*. Per scegliere una voce in Soundscape, apri il menu e seleziona *Impostazioni*, poi *Audio*, poi *Voci*.
{% endif %}
