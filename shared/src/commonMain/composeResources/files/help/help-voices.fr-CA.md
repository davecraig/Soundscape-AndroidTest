# Voix

{% if platform == "ios" %}
Soundscape peut utiliser toutes les voix installées sur votre iPhone, sauf les voix Siri. Les voix *Améliorées* sont les meilleures, mais vous devez d’abord les télécharger. Dans l’app Réglages d’iOS, allez dans Accessibilité > Lecture et énonciation > Voix et sélectionnez une voix. Avant iOS 26, *Lecture et énonciation* s’appelle *Contenu énoncé*. Pour choisir une voix dans Soundscape, ouvrez le menu et sélectionnez *Réglages*, puis *Audio*, puis *Voix*.
{% else %}
Soundscape peut utiliser toutes les voix installées sur votre téléphone. Pour ajouter des voix, ouvrez les paramètres de votre téléphone et cherchez *Sortie de la synthèse vocale*. Pour choisir une voix dans Soundscape, ouvrez le menu et sélectionnez *Réglages*, puis *Audio*, puis *Voix*.
{% endif %}
