# 음성

{% if platform == "ios" %}
Soundscape는 Siri 음성을 제외하고 iPhone에 설치된 어떤 음성이든 사용할 수 있습니다. *Enhanced* 음성이 가장 듣기 좋지만 먼저 다운로드해야 합니다. iOS 설정 앱에서 손쉬운 사용 > 읽기 및 말하기 > 음성으로 이동해 음성을 선택하세요. iOS 26 이전에는 *읽기 및 말하기*의 이름이 *음성 콘텐츠*입니다. Soundscape에서 음성을 고르려면 메뉴를 열고 *설정*, *오디오*, *음성*을 차례로 선택하세요.
{% else %}
Soundscape는 휴대폰에 설치된 어떤 음성이든 사용할 수 있습니다. 음성을 추가하려면 휴대폰 설정을 열고 *텍스트 음성 변환 출력*을 찾으세요. Soundscape에서 음성을 고르려면 메뉴를 열고 *설정*, *오디오*, *음성*을 차례로 선택하세요.
{% endif %}
