# Vozes

{% if platform == "ios" %}
O Soundscape pode usar qualquer voz instalada no seu iPhone, exceto as vozes da Siri. As vozes *Enhanced* (Aprimoradas) soam melhor, mas tem de as transferir primeiro. Na aplicação Definições do iOS, vá a Acessibilidade > Ler e Falar > Vozes e selecione uma voz. Antes do iOS 26, *Ler e Falar* chama-se *Conteúdo Falado*. Para escolher uma voz no Soundscape, abra o menu e selecione *Definições*, depois *Áudio* e depois *Vozes*.
{% else %}
O Soundscape pode usar qualquer voz instalada no seu telemóvel. Para adicionar vozes, abra as definições do telemóvel e procure *Saída de texto para voz*. Para escolher uma voz no Soundscape, abra o menu e selecione *Definições*, depois *Áudio* e depois *Vozes*.
{% endif %}
